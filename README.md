# Eolymp Weekly Programming Practice

This repository contains my solutions to the weekly programming problems I solve on Eolymp.

The purpose of this repository is to document my progress, practice problem solving, and improve my programming skills through consistent weekly practice.

## Structure

The solutions are organized by week:

```text
Week-01/
Week-02/
Week-03/
...
```

Each folder contains the solutions for that week's problems.

## Language

The solutions in this repository are primarily written in Python.

## Platform

[Eolymp](https://eolymp.com/)

I update this repository regularly as I complete new weekly problem sets.
